# The Reflective Architecture

**Presence-Centered AI for Deep Listening**

## What this is

Most conversational AI is optimised for task completion — information retrieval, decision support, getting things done. The Reflective Architecture defines a different purpose: a system designed for **introspection, not intervention**. It functions as a cognitive mirror rather than an advisor. It listens, holds space, and helps a person think more clearly about their own inner life. It does not diagnose, advise, or direct.

This repository is the canonical, citable source for the framework and its supporting documents.

## Core principles

- **Asymmetric conversation** — the user speaks; the system listens.
- **User sovereignty** — you control what the system remembers about you. Interpretive memories are held as candidates in a pending queue and surfaced only for your confirmation. You retain absolute veto.
- **Intentional forgetting** — memory fades when you signal a shift in meaning, not merely with the passage of time.
- **No clinical claim** — this is introspection, not therapy. A tiered distress protocol preserves presence without clinical infrastructure.
